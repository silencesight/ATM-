# Didactic ESL ATM - v1.1.0

Welcome to the Didactic ESL ATM Application! This desktop app is built specifically for classroom teachers to seamlessly manage a digital classroom economy.

## 🚀 What's New in Version 1.1.0
- **Store Catalog Management:** Add new items, edit existing reward cards, and permanently remove items with confirmation.
- **Shelf Visibility (Hide/Inactive):** Temporarily shelve items without losing them; hidden items are excluded from student shopping and purchase screens.
- **Custom Visuals & Emoji Picker:** Choose preset classroom card designs or pick from custom emojis (🍕, 🎮, 🎟️, 📚, 🏆, 🍿, 🍦, 🎧, ⭐, 🎁, 🚀, 👑, etc.) with real-time live preview.
- **Unlimited Stock Mode:** Mark rewards as always in stock with an "∞ Unlimited" badge.
- **Safe Catalog Reset:** Restore default items while safely preserving all custom added rewards.

---

## 📌 Version 1.0.0 Overview
- **Student Roster Management:** Add, edit, and organize students with unique ID numbers, balances, and credit scores.
- **Bulk Balance Adjustments:** Distribute or deduct "English Dollars" (E$) across entire classes or multiple students simultaneously with a single click. 
- **Loans & Credit Systems:** Issue loans to students, track outstanding debts, and penalize late payments. Credit scores dynamically calculate based on loan history.
- **Integrated Print Studio:** Automatically generate beautiful, printable Credit Card cutouts for students to hold physically in the classroom.
- **Data Safety:** Built-in `.json` snapshot engine to manually backup your classroom state.
- **Native Desktop Experience:** Completely standalone `.exe` built in Rust (Tauri), featuring a sleek dark mode UI, native drag-and-drop window controls, and custom scrollbars. 

### 🔧 Installation
1. Download `ATM_0.1.0_x64-setup.exe` below.
2. Double-click the installer to run it on your Windows machine. 
*(Note: If Windows SmartScreen displays a blue "Windows protected your PC" warning, simply click **More Info** -> **Run Anyway** to bypass. This is normal for indie and open-source tools!)*

### 📝 Notes for Teachers
- For best results, use the Print Studio on Letter or A4 paper with printer margins set to "Default" or "None". 
- Remember to back up your data weekly using the "Export Backup" button!
